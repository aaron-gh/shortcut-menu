# SVOX Pico

The text-to-speech engine that safe mode speaks with. These files are `pico/lib` from AOSP's
[platform/external/svox](https://android.googlesource.com/platform/external/svox) at commit
`c5a33e4fdc55b63d4aa33aecefcc91b63da921e7`, unchanged but for leaving out `Android.mk`. The voices
in `app/src/main/assets/pico` are from `pico/lang` at the same commit. They are licensed under the
Apache License 2.0: see `NOTICE`.
